# PBO — Object-Oriented Programming Coursework

Weekly exercises for "Pemrograman Berorientasi Objek" (Object-Oriented Programming). Each `week*` folder is a standalone set of Java programs: week3 covers basic I/O, a calculator, branching (grading) and loops (parking fee calculation); week4 covers 2D arrays; week7 covers abstract classes, inheritance, and a UML-based example; week9 covers interfaces and inheritance (animals, electric vehicles); week10 covers basic Swing/AWT GUIs including a login form.

## Tech Stack

Java (plain JDK, no build tool/framework)

## How to Run

1. Open the folder for the week/topic you want (e.g. `week9/edriveoop`).
2. Compile: `javac *.java`
3. Run the file containing `Main` (or the relevant entry class): `java Main`
